시행일: 2026년 11월 9일 · 개발자: Yongjun Cha

기기에 저장하는 정보

학습 기록, 직접 추가한 표현, 가져온 음성·영상에서 추출한 음성 및 전사문, 번역·AI 설명·생성 음성, API 사용량과 추정 비용은 기기에 저장합니다. 개발자는 별도의 계정 서버나 광고·행동 분석 서비스를 운영하지 않습니다. 기기 간 자동 동기화는 제공하지 않습니다. 기기 백업 설정에 따라 운영체제의 백업에 포함될 수 있습니다.

선택적인 OpenAI 기능

사용자가 본인의 API 키를 등록하고 전송에 명시적으로 동의한 경우, 새 번역·표현 설명·음성 생성 요청에 필요한 문장, 표현과 주변 문맥을 OpenAI API로 전송합니다. API 키는 요청 인증에 사용되며 기기 키체인에 보관하고 학습 기록 내보내기에 포함하지 않습니다. OpenAI는 계정과 요청 사용량 및 접속 정보 등을 자체 정책에 따라 처리합니다. 사용료는 등록한 API 계정에 발생할 수 있습니다.

원본 음성·영상은 OpenAI에 전송하지 않습니다. 지원 기기의 전사는 Apple의 기기 내 음성 인식으로 처리합니다. 최초 언어 모델 설치에는 인터넷이 필요할 수 있습니다. OpenAI 전송 동의를 끄면 새로운 AI 요청이 차단되며, 이미 저장한 결과는 계속 이용할 수 있습니다. 텍스트 생성 요청에는 응답 저장을 끄는 설정을 사용하지만, 서비스 제공자의 보안·오용 방지 보관까지 중단하는 것은 아닙니다.

OpenAI 개인정보 처리방침 · OpenAI API 데이터 처리 안내

외부 사전과 번역 사이트

네이버 사전 또는 파파고 버튼을 누르면 선택한 검색어·문장을 해당 사이트에 전달합니다. 해당 서비스의 개인정보 처리방침이 적용됩니다. 앱은 사전 사이트의 계정 정보를 수집하지 않습니다.

보관과 삭제

API 키는 OpenAI 연결 화면에서 삭제할 수 있습니다. 직접 추가한 표현과 듣기 자료는 앱에서 삭제할 수 있습니다. 앱을 삭제하면 앱의 로컬 자료가 삭제되지만, 내보낸 파일·운영체제 백업·키체인 항목은 별도로 남을 수 있으므로 API 키는 앱 삭제 전에 삭제하세요. 외부 서비스에 이미 전송한 정보의 보관·삭제는 해당 제공자의 정책과 계정 설정에 따릅니다. 사용자가 직접 내보내거나 공유한 파일은 수신처에서 별도로 관리합니다.
