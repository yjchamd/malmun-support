말문

영어 표현을 익히고, 듣고, 내 말로 연습하는 개인 학습 앱입니다.

사용 안내

오늘 탭에서 학습을 시작하고, 24주 과정과 표현 목록에서 카드를 선택하세요. 듣기 자료에서 직접 보유한 음성·영상을 가져올 수 있습니다. 기기 내 전사는 iOS 26 이상과 지원 기기·언어가 필요합니다.

AI 기능은 선택 사항입니다. 내 기록 → OpenAI 연결에서 본인의 API 키를 저장하고 문장 전송에 동의하면 사용합니다. API 이용료는 해당 OpenAI 계정에 발생할 수 있습니다. 저장된 결과는 오프라인에서 다시 이용합니다.
